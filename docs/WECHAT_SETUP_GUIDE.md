在开始之前，你需要准备以下信息：

- [ ] 企业 ID (Corp ID)
- [ ] 应用 AgentId
- [ ] 应用 Secret

## 🚀 快速配置步骤

### 第一步：登录企业微信管理后台

访问：https://work.weixin.qq.com/

使用管理员账号登录

---

### 第二步：获取企业 ID

1. 登录后，点击左下角「我的企业」
2. 在页面底部找到「企业信息」
3. 复制「企业 ID」

```
示例：ww1234567890abcdef
```

**✏️ 记录你的企业 ID：**
```
WECHAT_WORK_CORP_ID=_________________
```

---

### 第三步：创建自建应用

1. 点击「应用管理」
2. 点击「自建」标签
3. 点击「创建应用」按钮

**填写应用信息：**
- **应用名称**：iOS 崩溃符号化系统
- **应用介绍**：用于接收和处理 iOS 应用崩溃报告
- **应用 Logo**：上传一个图标（可选）

4. 点击「创建应用」

---

### 第四步：配置应用权限

创建应用后，进入应用详情页面：

1. **可见范围**
   - 点击「可见范围」右侧的「修改」
   - 选择需要接收崩溃报告的部门或成员
   - 建议：选择研发部门或相关技术人员

2. **接收消息**
   - 确保「接收消息」开关已打开

3. **API 权限**
   - 默认已有发送消息权限，无需额外配置

---

### 第五步：获取 AgentId 和 Secret

在应用详情页面：

1. **AgentId**
   - 在页面顶部可以看到「AgentId」
   - 这是一个数字，例如：1000002

```
示例：1000002
```

**✏️ 记录你的 AgentId：**
```
WECHAT_WORK_AGENT_ID=_________________
```

2. **Secret**
   - 在页面中找到「Secret」
   - 点击「查看」按钮
   - 可能需要扫码验证
   - 复制显示的 Secret

```
示例：abcdefghijklmnopqrstuvwxyz123456789ABCDEFG
```

**✏️ 记录你的 Secret：**
```
WECHAT_WORK_SECRET=_________________
```

⚠️ **重要提示**：Secret 只显示一次，请妥善保管！

---

### 第六步：配置环境变量

打开项目的 `backend/.env` 文件，填入刚才获取的信息：

```bash
# 企业微信配置
WECHAT_WORK_CORP_ID=ww1234567890abcdef
WECHAT_WORK_AGENT_ID=1000002
WECHAT_WORK_SECRET=abcdefghijklmnopqrstuvwxyz123456789ABCDEFG

# 系统访问地址（用于生成详情链接）
BASE_URL=http://10.1.106.95:5173
```

**配置说明：**
- `WECHAT_WORK_CORP_ID`：你的企业 ID
- `WECHAT_WORK_AGENT_ID`：应用的 AgentId
- `WECHAT_WORK_SECRET`：应用的 Secret
- `BASE_URL`：系统的访问地址（用于生成崩溃详情链接）

---

### 第七步：重启服务

配置完成后，重启后端服务：

```bash
# 停止当前服务（Ctrl+C）
# 然后重新启动
npm run dev
```

---

### 第八步：测试配置

#### 方法 1：使用 API 测试

```bash
# 检查配置状态
curl http://localhost:3000/api/wechat/config

# 应该返回：
# {"success":true,"data":{"configured":true}}

# 发送测试消息
curl -X POST http://localhost:3000/api/wechat/test \
  -H "Content-Type: application/json" \
  -d '{}'

# 如果配置正确，你应该在企业微信中收到测试消息
```

#### 方法 2：在前端测试

1. 打开浏览器访问系统
2. 进入历史记录页面
3. 点击任意一条记录的「分享到企业微信」按钮
4. 查看企业微信是否收到消息

## ❓ 常见问题

### Q1: 提示"企业微信未配置"

**A:** 检查以下几点：
1. `.env` 文件中的配置是否正确填写
2. 配置后是否重启了服务
3. 环境变量是否被正确加载

### Q2: 发送消息失败，提示 "invalid corpid"

**A:** 企业 ID 填写错误，请检查：
1. 企业 ID 是否完整复制
2. 是否有多余的空格
3. 是否使用了正确的企业 ID（不是企业名称）

### Q3: 发送消息失败，提示 "invalid agentid"

**A:** AgentId 填写错误，请检查：
1. AgentId 是否为纯数字
2. 是否复制了正确的 AgentId
3. 应用是否已创建成功

### Q4: 发送消息失败，提示 "invalid secret"

**A:** Secret 填写错误，请检查：
1. Secret 是否完整复制
2. 是否有多余的空格或换行
3. 如果忘记了 Secret，需要在企业微信后台重置

### Q5: 消息发送成功，但收不到

**A:** 检查以下几点：
1. 应用的可见范围是否包含你的账号
2. 是否关注了该应用
3. 企业微信是否正常登录
4. 检查企业微信的消息设置

### Q6: 如何获取用户 ID？

**A:** 用户 ID 不是微信号，获取方法：
1. 在企业微信管理后台
2. 进入「通讯录」
3. 找到对应成员
4. 查看「账号」字段，这就是用户 ID

### Q7: 如何获取部门 ID？

**A:** 部门 ID 获取方法：
1. 在企业微信管理后台
2. 进入「通讯录」
3. 点击部门名称
4. 在 URL 中可以看到部门 ID（partyid 参数）
