# 自动触发 AI 分析功能说明

## 功能概述

符号化完成后，当用户切换到"AI 智能分析"标签页时，如果还没有进行过 AI 分析，系统会自动触发 AI 分析，无需手动点击"AI 智能分析"按钮。

## 使用场景

### 场景1：符号化后立即查看 AI 分析

1. 用户粘贴崩溃日志
2. 选择 dSYM 文件
3. 点击"开始符号化"
4. 符号化完成后，切换到"AI 智能分析"标签页
5. **系统自动触发 AI 分析**（无需手动点击按钮）
6. 等待分析完成，查看结果

### 场景2：已经分析过，再次查看

1. 符号化完成后，已经进行过 AI 分析
2. 切换到其他标签页（如"原始日志"）
3. 再次切换回"AI 智能分析"标签页
4. **不会重复触发分析**，直接显示之前的分析结果

### 场景3：没有 API Key

1. 符号化完成后，没有输入 API Key
2. 切换到"AI 智能分析"标签页
3. **不会触发分析**，显示提示信息
4. 输入 API Key 后，可以手动点击"AI 智能分析"按钮

## 触发条件

自动触发 AI 分析需要同时满足以下条件：

1. ✅ 已完成符号化（`result` 不为空）
2. ✅ 还没有进行过 AI 分析（`result.analysis` 为空）
3. ✅ 当前没有正在进行的分析（`isAnalyzing` 为 false）
4. ✅ 已输入 API Key（`apiKey` 不为空）
5. ✅ 切换到"AI 智能分析"标签页（`activeKey === 'analysis'`）

## 实现细节

### 标签页切换处理

```typescript
const handleTabChange = (activeKey: string) => {
  // 如果切换到 AI 分析标签页，且还没有分析过，自动触发分析
  if (activeKey === 'analysis' && result && !result.analysis && !isAnalyzing && apiKey) {
    handleAIAnalysis();
  }
};
```

### Tabs 组件配置

```typescript
<Tabs
  defaultActiveKey="symbolicated"
  onChange={handleTabChange}
  items={[...]}
/>
```

### 视觉反馈

在"AI 智能分析"标签页标题上添加完成标记：

```typescript
{
  key: 'analysis',
  label: (
    <Space>
      <RobotOutlined />
      AI 智能分析
      {result.analysis && <Text type="success" style={{ fontSize: '12px' }}>✓</Text>}
    </Space>
  ),
  children: <AIAnalysisPanel analysis={result.analysis || null} loading={isAnalyzing} />
}
```

## 用户体验改进

### 改进前
1. 符号化完成
2. 切换到"AI 智能分析"标签页
3. 看到空白或提示信息
4. 返回上一个标签页
5. 点击"AI 智能分析"按钮
6. 等待分析完成
7. 再次切换到"AI 智能分析"标签页查看结果

**操作步骤：7 步**

### 改进后
1. 符号化完成
2. 切换到"AI 智能分析"标签页
3. **自动开始分析**
4. 等待分析完成，直接查看结果

**操作步骤：4 步**

**减少了 3 个操作步骤，提升了用户体验！**

## 状态指示

### 分析前
- 标签页标题：`🤖 AI 智能分析`
- 内容：空白或提示信息

### 分析中
- 标签页标题：`🤖 AI 智能分析`
- 内容：加载动画 + "AI 分析中..."

### 分析完成
- 标签页标题：`🤖 AI 智能分析 ✓`
- 内容：分析结果（摘要、崩溃类型、可能原因、建议等）

## 错误处理

### 没有 API Key
- 不会自动触发分析
- 显示提示：`请输入 OpenAI API Key`
- 用户需要输入 API Key 后手动点击按钮

### API 调用失败
- 显示错误提示
- 用户可以重新点击"AI 智能分析"按钮重试

### 网络超时
- 显示超时错误
- 用户可以重新点击按钮重试

## 与手动分析按钮的关系

### 手动按钮的作用
1. 在符号化完成后，不切换标签页，直接点击按钮分析
2. 分析失败后，重新点击按钮重试
3. 没有 API Key 时，输入后点击按钮分析

### 自动触发的作用
1. 减少用户操作步骤
2. 提升用户体验
3. 符合用户预期（切换到分析标签页就是想看分析结果）

**两者互补，不冲突**
