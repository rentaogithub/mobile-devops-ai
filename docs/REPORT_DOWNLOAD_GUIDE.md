# 符号化报告下载功能指南

## 功能概述

符号化报告下载功能允许用户将符号化结果和AI分析报告打包成ZIP文件下载，方便保存和分享。

## 功能特点

### 1. 完整的报告包
下载的ZIP文件包含：
- **符号化日志文件**（.txt格式）：完整的符号化后的崩溃堆栈
- **AI分析报告**（.pdf格式）：专业的崩溃分析报告（如果有AI分析）

### 2. 专业的PDF报告
AI分析报告PDF包含：
- 基本信息（应用版本、崩溃线程、崩溃模块等）
- 崩溃摘要
- 可能原因列表
- 修复建议列表
- 受影响组件
- 崩溃堆栈快照

### 3. 便捷的下载方式
- 一键下载，无需额外操作
- 自动命名，包含版本号和时间戳
- 支持权限控制（如果启用了认证）

## 使用方法

### 从历史记录下载

1. **进入历史记录页面**
   - 点击导航栏的"历史记录"

2. **选择要下载的记录**
   - 点击记录卡片上的"查看详情"按钮

3. **下载报告**
   - 在详情弹窗底部，点击"下载报告"按钮
   - 浏览器会自动下载ZIP文件

4. **查看报告**
   - 解压ZIP文件
   - 查看符号化日志文件（.txt）
   - 如果有AI分析，查看PDF报告

### 文件命名规则

**ZIP文件名格式：**
```
crash_report_{版本号}_{时间戳}.zip
```

例如：`crash_report_5.12.3_1732604829000.zip`

**ZIP内文件：**
- `symbolicated_crash_{版本号}_{时间戳}.txt` - 符号化日志
- `ai_analysis_report_{版本号}_{时间戳}.pdf` - AI分析报告（如果有）

## PDF报告内容

### 1. 基本信息
- 应用版本
- 崩溃线程
- 崩溃模块
- 崩溃类型
- 严重程度（低/中/高/严重）

### 2. 崩溃摘要
简短的崩溃描述，概括问题的核心。

### 3. 可能原因
列出导致崩溃的可能原因，帮助快速定位问题。

### 4. 修复建议
提供具体的修复建议和最佳实践。

### 5. 受影响组件
列出受此崩溃影响的系统组件或模块。

### 6. 崩溃堆栈快照
显示崩溃时的堆栈信息前10行，便于快速查看。

### 7. 生成时间
报告生成的时间戳，便于追踪。

## 技术实现

### 后端实现

#### 1. ReportGeneratorService
```typescript
class ReportGeneratorService {
  // 生成AI分析报告PDF
  generateAIAnalysisPDF(analysis: CrashAnalysis): Promise<Buffer>
  
  // 生成ZIP文件
  generateReportZip(
    symbolicatedLog: string,
    analysis?: CrashAnalysis,
    appVersion?: string
  ): Promise<Buffer>
}
```

#### 2. 下载路由
```typescript
GET /api/history/:id/download
```

**功能：**
- 根据历史记录ID获取记录
- 生成ZIP文件（包含日志和PDF）
- 设置正确的响应头
- 返回文件流

### 前端实现

#### 1. API方法
```typescript
historyApi.downloadReport(id: number, appVersion: string): void
```

**功能：**
- 创建下载链接
- 处理认证令牌
- 触发浏览器下载

#### 2. UI组件
在历史记录详情弹窗的footer中添加"下载报告"按钮。

## 使用场景

### 场景1：保存崩溃记录
将重要的崩溃记录下载保存，便于长期存档和追踪。

### 场景2：分享给团队
将崩溃报告分享给其他开发人员或测试人员，协同解决问题。

### 场景3：提交Bug报告
将完整的崩溃报告附加到Bug追踪系统中。

### 场景4：离线分析
下载报告后可以在没有网络的环境下查看和分析。

### 场景5：文档归档
将崩溃报告作为项目文档的一部分进行归档。

## 注意事项

### 1. 文件大小
- 符号化日志文件大小取决于崩溃日志的长度
- PDF报告通常在几十KB到几百KB之间
- ZIP文件会进行压缩，通常比原始文件小30-50%

### 2. 下载权限
- 如果启用了认证，需要登录后才能下载
- 管理员和普通用户都可以下载报告

### 3. PDF生成
- 如果没有AI分析结果，ZIP中只包含符号化日志
- PDF生成失败不会影响日志文件的下载
- PDF使用中文显示，便于阅读

### 4. 浏览器兼容性
- 支持所有现代浏览器
- 自动处理文件下载
- 支持大文件下载
