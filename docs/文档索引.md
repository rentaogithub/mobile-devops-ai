## 维护规则

同一主题只维护上述一个归属章节；不再新增重复的专项使用指南。合并的历史需求与实施计划保留核心约束、待办和验收条件，详细历史通过 Git 追溯。

当前功能、部署步骤与未来目标分别描述。修改页面、API、配置或执行语义时同步对应章节及链接。三个架构图保留 PNG 预览和 SVG 源文件，修改时同步两种格式。

[OpenSpec 规范](../openspec/project.md)和[变更任务台账](../openspec/changes/formalize-recording-orchestration/tasks.md)继续承担规范与交付状态，不搬入或复制到使用指南；本次收敛未改变任何任务勾选或补做外部服务验收。
