# Mobile DevOps AI 安装指南

本指南用于从源码启动 Mobile DevOps AI。完整的生产部署、数据目录和服务管理说明见[部署与运行](部署与运行.md)。

## 环境要求

- Node.js 22
- npm
- Rust stable，用于编译水印解码器
- SQLite 原生构建工具链
- macOS 与兼容版本的 Xcode，仅在运行 iOS 构建、真机质检和符号化任务时需要

## 获取和安装

```bash
git clone https://github.com/rentaogithub/mobile-devops-ai.git
cd mobile-devops-ai
npm ci
```

复制并填写后端环境配置。不要提交真实密码、Token、证书或私钥。

```bash
cp backend/.env.example backend/.env
```

如果仓库版本未提供 `.env.example`，请根据[部署与运行](部署与运行.md)配置 `backend/.env` 中的数据路径、管理员凭据和外部服务参数。

## 本地运行

```bash
npm run dev
```

默认前端地址为 `http://localhost:5173`，后端地址为 `http://localhost:3000`。实际后端端口以环境变量 `PORT` 为准。

## 发布前验证

```bash
npm run check
npm run build
npm audit --omit=dev --audit-level=high
cargo audit --file backend/tools/watermark-decoder-rs/Cargo.lock
```

其中 `npm run check` 执行类型检查和自动化测试，`npm run build` 构建前端、后端与 Rust 组件。

## 生产运行

```bash
./start-platform.sh start
./start-platform.sh status
```

生产部署前应设置独立的数据目录、最小权限账号、HTTPS 反向代理和备份策略。升级前先备份数据库与上传文件，再按 `CHANGELOG.md` 检查兼容性说明。
